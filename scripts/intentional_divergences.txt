# INTENTIONAL DIVERGENCES — fixtures where framec-ng is deliberately NOT byte-identical to the
# legacy oracle because ng FIXES a legacy bug.
#
# Owner ruling (2026-07-24): legacy's bugs are FIXED in ng, not reproduced. Byte-faithfulness is
# the bar EVERYWHERE ELSE; a fixture listed here can never go byte-identical, by design.
#
# RULES for adding an entry — all three are required:
#   1. Name the legacy bug precisely (what legacy emits, why it is wrong).
#   2. Point at the VALIDATING FIXTURE — a cleanroom test that PROVES the fix, designed to FAIL on
#      legacy and PASS on ng. Prefer RUNTIME validation (compile the emitted code, run it, assert
#      observable behavior), modelled on
#      compiler/tests/two_backends.rs::lifecycle_handlers_run_with_args_on_both_backends.
#   3. Record the divergence in a code comment at the emit site too, so it is deliberate in-tree.
#
# Anything NOT listed here must be byte-identical to legacy. This file is the allowlist the
# faithfulness ratchet (faithfulness_diff.sh) excludes from its denominator — keep it SHORT and
# justified; it is not a place to park "ng is different and we haven't fixed it yet".
#
# Format: <subpath-under-tests/common/positive/>  # <the legacy bug this fixes>
#

# D2 — constructor cannot construct (journal DIVERGENCE-JOURNAL.md#D2).
#   legacy: `def __init__(self)` takes no header params; domain seeding + start-compartment
#           enter-args live only in `_create`. A plain `Sys(args)` -> TypeError; `Sys()` leaves
#           domain fields unassigned. ng: `__init__(self, <params>)` seeds domain + builds the

#   the legacy empty `__prepareEnter("Start",[],[])` placeholder, `c.__next_compartment=None`) and
#   NOTHING else; runtime output is byte-identical (harness builds via @@Sys(...) -> _create).

# --- D2 (Rust spelling) — PARAMETERIZED-only (journal DIVERGENCE-JOURNAL.md#D2-rust). ------------
#   legacy (-l rust): emits NO `pub fn new(<params>)`; inlines the struct literal straight into
#     `pub fn __create(<params>)`, so `Sys::new(p)` is a compile error and a Sys can only be built by

#     so ONLY parameterized systems are listed. State-var seeding ($.x=V) is NOT a Rust divergence
#     (legacy seeds it structurally via the typed-context Default impl, run in both new() and
#     __create()) — do NOT list any Rust fixture under D3.

# D3 — state-vars only seed via `_create` (journal DIVERGENCE-JOURNAL.md#D3).
#   legacy: `$.x` initializers go into a synthesized `$>` handler guarded by
#           `if "n" not in compartment.state_vars:`, which only runs via `_create`; `Sys().peek()`
#           -> KeyError. ng: seeds the compartment's state_vars where the compartment is BUILT
#           (in __init__ for the start state, in each transition for a destination) — so the same
#           `$.x` may be seeded at N build sites where legacy emitted one guarded seed.
#   Validator: compiler/tests/legacy_bug_fixes.rs::state_vars_are_seeded_for_a_plain_constructor.
#   Each fixture below verified (this run, vs the LOCAL 4.6.0.x oracle): the ENTIRE code delta is
#   the state-var seed relocation (legacy `if "X" not in ... : compartment.state_vars["X"]=V` ->
#   ng `[__|self.__]compartment.state_vars["X"]=V` at each build site, SAME (X,V)) and NOTHING
#   else; runtime output is byte-identical.
# =============================================================================================
